# Iteration & Aggregation

Iterating over pool data with forEach/map/filter/reduce and aggregating statistics.

## Source Code

[View on GitHub](https://github.com/rayenboussayed/object-pools/blob/main/examples/iteration.ts)

## Running

```bash
npm run example:iteration
```

## Features Demonstrated

-   forEach, map, filter, reduce over pool data
-   some / every checks
-   find / findIndex lookups
-   Chaining iteration with queries
-   Statistics and custom aggregation
-   Side effects and nested pools

See the [source code](https://github.com/rayenboussayed/object-pools/blob/main/examples/iteration.ts) for the complete implementation.
